# 외동중학교 다국적언어 가정통신문 제작기

외동중학교의 실제 가정통신문 예시를 바탕으로 만든 템플릿 기반 시안입니다. PDF 글자를 그대로 추출하지 않고 제목, 인사말, 핵심 정보, 표, QR코드, 이미지, 동의서를 블록으로 작성하여 A4 문서로 조립합니다.

## 현재 구현된 기능

- 외동중학교 공통 머리글과 학교장 영역
- 키워드를 이용한 한국어 인사말 자동생성
- 일시, 장소, 대상, 신청 방법, 비용, 마감일, 문의처 입력
- 표의 행과 열 추가 및 셀별 입력
- 사이트 주소를 이용한 QR코드 자동생성
- 이미지와 화면 캡처 추가
- 절취선과 참가 동의서 자동생성
- 한국어, 베트남어, 러시아어, 영어, 중국어, 싱할라어 검토 탭
- 언어별 고정 항목 번역
- 브라우저 저장 및 가정통신문함
- 교사 화면과 삭제 기능 비밀번호 보호
- 인쇄 기능을 이용한 PDF 저장

초기 교사 비밀번호는 `6673`입니다.

## 번역에 관한 중요한 안내

현재 배포본에는 번역 API 키가 들어 있지 않습니다. 실제 번역 서버가 연결되지 않은 상태에서 외국어 버튼을 누르면 한국어 내용을 외국어라고 속여 표시하지 않고, `번역 서버 연결 필요`라고 안내합니다.

실제 번역은 `src/services/translationService.ts`에서 학교가 관리하는 번역 서버를 호출하도록 설계되어 있습니다. `.env`에 다음 주소를 설정하면 구조화된 문서 전체를 서버로 전달하고 번역 결과를 받습니다.

```text
VITE_TRANSLATION_API_URL=https://학교에서-관리하는-번역서버/translate
```

서버는 다음 원칙으로 번역해야 합니다.

- 제목, 인사말, 본문을 문맥에 맞게 번역
- 표의 행과 열 구조를 유지하고 셀별로 번역
- 날짜, 시간, 전화번호, 금액을 원문과 대조
- URL과 QR코드 값은 변경하지 않음
- 학생 이름 등 개인정보는 외부 번역 서비스에 보내지 않음

브라우저 화면에 API 키를 직접 저장하면 안 됩니다. 실제 학교 운영 전에는 서버 인증, 개인정보 보호, 번역 결과 검토 기능을 추가해야 합니다.

## 실행 방법

Node.js 20 이상에서 다음 명령을 실행합니다.

```bash
npm install
npm run dev
```

배포 파일 생성:

```bash
npm run build
```

생성된 `dist` 폴더 안의 파일과 `assets` 폴더를 웹서버에 함께 올립니다.

## 사용 순서

1. 교사 제작 탭에서 비밀번호 `6673`을 입력합니다.
2. 제목과 핵심 내용을 입력하고 인사말을 생성합니다.
3. 필요한 표, QR코드, 이미지, 동의서를 추가합니다.
4. A4 미리보기를 확인합니다.
5. 언어별 번역 결과를 검토합니다.
6. 가정통신문함에 저장합니다.
7. 브라우저 인쇄 메뉴에서 PDF로 저장합니다.

## 저장 방식의 한계

현재 문서는 서버가 아니라 해당 브라우저의 `localStorage`에 저장됩니다. 다른 컴퓨터나 휴대전화와 공유되지 않으며 브라우저 데이터를 삭제하면 문서도 삭제됩니다. 실제 배포 단계에서는 학교 서버 저장소와 로그인 기능이 필요합니다.
