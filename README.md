# 외동중학교 다국적언어 가정통신문 제작기

외동중학교의 실제 가정통신문 4개를 분석해 만든 템플릿 기반 웹앱입니다. 교사는 제목·인사말·본문·표·QR코드·동의서를 조립하고, 문서 전체를 여러 언어로 번역해 학생과 학부모에게 제공합니다.

## 구현된 기능

- 제공된 교표를 참고해 새로 제작한 고해상도·투명 배경 로고 사용
- 인사말은 `자동작성/직접 작성`을 선택하고, 키워드로 작성한 뒤 자유 수정
- 안내 내용도 `자동작성/직접 작성`을 선택하고 키워드로 작성
- `일시`, `장소`, `대상`, `신청 마감`, `참가비`, `문의처`, `신청 방법 및 활동 내용`, `준비물`마다 표시 여부 체크박스 제공
- 각 항목 제목은 `기본 제목/직접 입력` 중 선택하며, 직접 입력을 고르면 제목 이름을 자유롭게 변경
- `일시`에만 달력과 `시간/교시` 선택기를 제공
- 날짜는 `2026. 7. 27.(월)` 형식으로 자동 표기
- 시간은 24시간제로 시작·종료 시간을 선택하여 `13:30~16:30`으로 표기
- 교시는 시작·종료 교시를 숫자로 입력하여 `2교시~4교시`로 표기
- 일시 영역은 편집 화면의 전체 폭을 사용하며 시작·종료 시계 버튼과 교시 숫자가 잘리지 않도록 큰 입력칸 제공
- `신청 마감`을 포함한 나머지 항목은 제목 용도가 바뀔 수 있도록 달력 없이 일반 입력칸 제공
- 본문 표의 가로 행·세로 열 추가와 삭제
- 자유형 동의서 제목·문구·작성란 수정
- 동의서 내부에 별도의 자유 표 추가
- QR코드를 여러 개 생성하고 옆으로 배열
- 이미지와 화면 캡처 삽입
- 제목·인사말·본문·핵심정보·표·QR 설명·동의서 전체 번역
- 한국어, 베트남어, 러시아어, 영어, 중국어 간체, 싱할라어
- 학생·학부모 탭에서 언어 버튼으로 번역본 열람
- 교사용 가정통신문함, 삭제, PDF 저장·인쇄
- 초기 교사 비밀번호 `6673`과 비밀번호 변경

## 실제 번역 방식과 한계

별도 API 키 없이 시안을 바로 시험할 수 있도록 MyMemory 공개 번역 서비스를 사용합니다. 교사가 언어 버튼이나 `전체 언어 번역`을 누르면 문서 내용이 외부 번역 서비스로 전송됩니다.

공개 번역 서비스는 다음 한계가 있습니다.

- 인터넷 연결이 필요합니다.
- 서비스 사용량 제한이나 일시 장애로 번역이 실패할 수 있습니다.
- 학교 문서의 전문 용어가 부정확하게 번역될 수 있습니다.
- 개인정보나 민감정보가 포함된 문서를 전송하면 안 됩니다.
- 공개 서비스만으로 전문 번역 품질을 100% 보장할 수 없습니다.

요일, 표 제목, 대상, 무료 등 자주 쓰는 학교 용어에는 언어별 고정 용어사전을 우선 적용합니다. 그래도 실제 배포 전에는 교사가 번역 결과를 반드시 검토해야 합니다.

학교 정식 운영판에서는 `src/services/translationService.ts`를 학교가 계약한 OpenAI API, Google Cloud Translation, Azure Translator 등의 서버 API로 교체하는 것을 권장합니다. API 키는 브라우저에 넣지 말고 학교 서버에서 관리해야 합니다.

## 키워드 자동작성에 관한 안내

현재 배포 ZIP에는 생성형 AI API 키를 안전하게 포함할 수 없으므로, 가정통신문 사례에 맞춘 학교 문서용 문장 규칙을 사용해 키워드 자동작성을 제공합니다. 방과후학교, 안전교육, 의견 수렴, 행사·체험 등의 키워드를 구분하여 정중한 문장을 만들며 교사가 바로 수정할 수 있습니다.

자유로운 AI 문장 생성을 사용하려면 학교가 관리하는 별도 AI 서버와 개인정보 보호 설정이 필요합니다. API 키를 공개 웹앱 안에 직접 넣는 방식은 사용하지 않아야 합니다.

## 저장 및 공유의 한계

현재 문서는 해당 브라우저의 `localStorage`에 저장됩니다. 같은 웹주소라도 다른 컴퓨터나 휴대전화에서는 문서가 보이지 않습니다. 실제 학부모 공유를 위해서는 데이터베이스와 학교 서버 저장 기능이 필요합니다.

브라우저 데이터를 삭제하면 저장된 가정통신문도 삭제됩니다. 중요한 문서는 `PDF로 저장·인쇄` 버튼으로 별도 보관하세요.

## 실행 방법

Node.js 20 이상에서 실행합니다.

```bash
npm install
npm run dev
```

배포 파일 생성:

```bash
npm run build
```

생성된 `dist` 폴더의 `index.html`과 `assets` 폴더를 GitHub Pages 또는 웹서버에 함께 올립니다.

## 사용 순서

1. 교사 제작 탭에서 비밀번호 `6673`을 입력합니다.
2. 필요한 항목만 체크하고, 제목은 `기본 제목/직접 입력` 중 선택합니다.
3. `일시`는 달력으로 날짜를 고른 뒤 `시간/교시` 중 하나를 선택하고, 나머지 항목은 내용을 직접 입력합니다.
4. 필요한 표·동의서·QR코드·이미지를 추가합니다.
5. 언어 버튼 또는 `전체 언어 번역`을 누릅니다.
6. 언어별 A4 미리보기를 확인합니다.
7. `가정통신문함에 저장·공개`를 누릅니다.
8. 학생·학부모 탭에서 언어별로 열람합니다.
9. 필요하면 PDF로 저장합니다.
